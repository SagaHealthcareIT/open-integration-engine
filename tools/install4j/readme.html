OpenShare Engine is Saga IT's build of the Open Integration Engine, licensed under the Mozilla Public License 2.0. The complete source code for this release, including our modifications, is published at github.com/SagaHealthcareIT/open-integration-engine (branch openshare, tagged openshare-v<version> per release).

This installer sets up a fully functional version of the engine with minimal user input, or upgrades an existing installation. The installer requires administrator permissions to run and install services.

Notes

  • A native service is installed and started right away, and is configured to start automatically at boot.
  • The OpenShare admin-console plugin shipped alongside this installer is installed automatically — keep it in the same folder as the installer.
  • A new installation has one user, admin. If you downloaded the engine from the OpenShare console, its password is the one the console showed you. Otherwise the engine generates a password on its first start and writes it once to logs/mirth.log (look for "Initial admin password"). An upgrade keeps your existing users and passwords.
  • A new installation uses the default configuration files in the conf directory; the installer does not prompt for customization. This includes ports (default: 8080 and 8443), log and app data paths, and password requirements.
  • An upgrade replaces the program files from the previous installation. Files in the conf directory are kept and are not updated with new defaults. Directories created at runtime, such as appdata, are also kept.
